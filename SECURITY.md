# Política de segurança

## Versões com suporte

Somente a versão publicada mais recente do Kit Dev Brasil recebe correções de segurança.

## Como reportar uma vulnerabilidade

**Não abra issues públicas para problemas de segurança.**

Reporte de forma privada pelos Security Advisories do GitHub:

1. Abra a [aba Security](https://github.com/GabrielCordeiroBarrosoTeles/kit-dev-brasil/security) do repositório.
2. Clique em **Report a vulnerability** ([link direto](https://github.com/GabrielCordeiroBarrosoTeles/kit-dev-brasil/security/advisories/new)).
3. Descreva o problema, o impacto e como reproduzir.

Você recebe uma resposta em até 7 dias. Confirmado o problema, a correção é preparada de forma privada e publicada o quanto antes, com crédito para você no aviso, a menos que prefira ficar anônimo.

## Escopo

Estão no escopo a extensão, qualquer ponto em que dados digitados pelo usuário (PIX, boleto, documentos) possam sair da máquina sem consentimento, a consulta opcional de CEP e o pipeline de publicação.
